# MaxiMos Store
A responsive single-page menswear storefront prototype.

## Run locally
Open `index.html` in a modern browser. An internet connection is needed for Google Fonts and Unsplash product photography.

## Customize
- Edit the `products` array near the bottom of `index.html` to change product names, EGP prices, descriptions, and image URLs.
- WhatsApp checkout number is configured as `201030207079`.
- Replace sample product photography with your own product images before launch.
- Replace sample shipping/return terms with your actual store policies.

## Important before production
This is a front-end demo. Cart data is held in browser memory and orders are sent to WhatsApp. There is no admin dashboard, database, inventory sync, or persistent order history. The sample reviews and 4.9 rating are illustrative placeholders and should be replaced with genuine customer feedback. Confirm shipping and return terms before publishing.
