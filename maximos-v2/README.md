# MaxiMus V2 — Independent Storefront

This folder is the independent redesign prototype for MaxiMus. It is intentionally isolated from the current production storefront.

## Visual direction
- MAFIA-inspired editorial luxury and typography
- NO RULES-inspired minimal product merchandising
- ORZR-inspired product detail, color and gallery interactions
- FOREVER-inspired store structure, bag and account entry points

## Preview deployment
Create a **new Vercel project** connected to this repository and set **Root Directory** to `maximos-v2`. Do not change the existing `maximus-eg` project or its production domain while this version is being built and tested.

## Current implementation stage
This is the first independent front-end prototype. Demo products and the cart are local to this browser. The account, newsletter persistence, admin panel, database, and official WhatsApp checkout still need to be connected before production use.
